\section{Output events and \commitment bases}
\label{app:bases}

This appendix first gives the formal definition of the lifted output events of
Section~\ref{sec:lifted-output-events}.  It then supplies the details behind
Section~\ref{sec:systems}: the canonical \commitments of
Sections~\ref{sec:functional-calm}--\ref{sec:complete-calm}
are \commitments (Definition~\ref{def:commitment}) and form a canonical basis,
compound \commitments behave like single ones, and every run under any basis
has an observably equivalent canonical run that retains at least as many rows
after each event.  \Commitments are partial functions, so a basis may make an
\commitment available only at states satisfying a precondition of its own.

\subsection{Lifted output events}
\label{app:lifted-output-events}

Fix a state $(i,R)$ and an output $o\in R(i)$.  A row is \emph{ruled out by}
$o$ when its output does not \outrelbase $o$.  The ruled-out rows fall into two
disjoint sets:
\begin{align}
  \Subsumed_o&=\{(k,x)\in R\setminus R[\mathrm{out}\OutputGe o]:\notag\\
    &\qquad\quad x\OutputOrd u\text{ for some }u\in R[\mathrm{out}\OutputGe o](k)\},
      \label{eq:output-subsumptions}\\
  \Excluded_o&=(R\setminus R[\mathrm{out}\OutputGe o])\setminus\Subsumed_o.
      \label{eq:commitment-removals}
\end{align}

\begin{definition}[Lifted output event, output subsumption]
\label{def:lifted-output-event}
Let $(i,R)$ be a state and $o\in R(i)$.  The \emph{output event}
$\mathsf{output}(o)$ keeps exactly the rows whose outputs \outrelbase $o$ and
emits $o$, atomically, ending at $(i,R[\mathrm{out}\OutputGe o])$ as in
Equation~\ref{eq:output-action}.  It removes each row $(k,x)$ in
$\Subsumed_o$, for which some $u\in R(k)$ \outrel both $x$ and $o$, by
\emph{output subsumption}, which is not a \commitment.
\end{definition}

\begin{definition}[Canonical \commitment]
\label{def:canonical-commitment}
When $\Excluded_o\neq\varnothing$, the output event applies the \emph{canonical
\commitment} $x_o$:
\begin{equation}
  x_o(i,R)=\bigl(i,\ R\setminus\Excluded_o\bigr).
  \label{eq:canonical-commitment-relational}
\end{equation}
  Thus $x_o$ removes exactly the rows in $\Excluded_o$.  At an input $k$, if
  $\Excluded_o(k)=R(k)$, it rules out $k$; otherwise it rules out only the
  outputs in $\Excluded_o(k)$.  A row in $\Subsumed_o(k)$ has a kept \outnoun
  at $k$.  The output event removes that row separately by output subsumption,
  and its kept \outnoun prevents the event from ruling out $k$.
\end{definition}

In Figure~\ref{fig:ambiguity-frames}(f), emitting $[A,B]$ places the row for
$[B,A]$ in $\Excluded_o$, so the event rules out that output at $\{A,B\}$.
In panel~(g), the two removed route sets are in $\Subsumed_o$, each
\outrelpast by a retained route set, so the event subsumes them without
\commitment.  With one row per input, $\Subsumed_o$ is empty, and $x_o$ rules
out each input whose row is removed; this is the functional output event of
Definition~\ref{def:output-event}.  Apart from these, a row leaves the
remainder table only by input loss (\S\ref{sec:functional-events}).

Legality lifts with the event: $o$ is a legal output when $\mathsf{output}(o)$
applies no \commitment, exactly when $\Excluded_o$ is empty, though the event may
still subsume the rows in $\Subsumed_o$.  The legal-output test lifts as well:

\begin{proposition}[Legal-output test]
\label{prop:exposability}
An output $o\in R(i)$ is legal at $(i,R)$ if and only if, for every legal
$j\InputGe i$ and $x\in R(j)$, some $u\in R(j)$ \outrel both:
\begin{equation}
  o\OutputOrd u
  \qquad\text{and}\qquad
  x\OutputOrd u.
  \label{eq:safe-exposure}
\end{equation}
\end{proposition}

\begin{proof}
The event $\mathsf{output}(o)$ applies no \commitment exactly when every
ruled-out row $(j,x)$ lies in $\Subsumed_o$, that is, is \outrelpast by some row
$(j,u)$ \outrelpart $o$.  Rows that already \outrelbase $o$ satisfy the stated
test with $u=x$, so this is exactly the stated test.
\end{proof}

This test marks the \commitment boundary: if it fails, emitting $o$ requires an
\commitment.

\subsection{\Commitment bases and compound \commitments}
\label{app:commitment-bases}

\begin{definition}[Canonical basis]
\label{def:canonical-commitment-basis}
The \emph{canonical \commitment basis} collects the canonical \commitments of
Definition~\ref{def:canonical-commitment},
\begin{equation}
  \mathcal B_P
    =\{x_o:o\in O,\ \operatorname{dom}(x_o)\neq\varnothing\},
  \label{eq:canonical-commitment-basis-relational}
\end{equation}
where $x_o$ is defined at the states with $o\in R(i)$ and $\Excluded_o\neq\varnothing$.
\end{definition}

\begin{definition}[Canonical event]
\label{def:canonical-event}
The \emph{canonical event} for $o$ at $(i,R)$ is the output event
$\mathsf{output}(o)$ of Definition~\ref{def:lifted-output-event}, which
applies $x_o$ when $\Excluded_o\neq\varnothing$ and no \commitment otherwise;
with one row per input it is the output event of
Definition~\ref{def:output-event}.
\end{definition}

Every output event of a system (Definition~\ref{def:system-output-event}) is
therefore canonical.  A system's own \commitments appear only in its
\commitment events.

\paragraph{The canonical \commitment is a \commitment.}
Suppose a removed row $(k,x)\in\Excluded_o$ were \outrelpast by a row $(k,y)$
that $x_o$ leaves.  Either $y$ \outrel $o$, or $y\in\Subsumed_o$ and is
\outrelpast by a row \outrelpart $o$.  By transitivity, $x$ is then
\outrelpast by a row \outrelpart $o$, so $x\in\Subsumed_o$, a contradiction.

\begin{lemma}[Output containment]
\label{lem:output-containment}
Let $(i,R)$ be a state and $o\in R(i)$.
\begin{enumerate}
  \item The output event $\mathsf{output}(o)$ takes $(i,R)$ to
        $(i,R[\mathrm{out}\OutputGe o])$.  It applies a \commitment, $x_o$,
        exactly when $o$ is not a legal output.
  \item If $(i,\widehat R)$ is a state with $R\subseteq\widehat R$, then
        $o\in\widehat R(i)$, and $\mathsf{output}(o)$ takes $(i,\widehat R)$
        to $(i,\widehat R[\mathrm{out}\OutputGe o])$, which contains
        $R[\mathrm{out}\OutputGe o]$.
\end{enumerate}
\end{lemma}

\begin{proof}
(1) The event keeps exactly the rows whose outputs \outrelbase $o$
(Definition~\ref{def:lifted-output-event}), and it applies $x_o$ exactly when
$\Excluded_o\neq\varnothing$, that is, when $o$ is not legal.  (2) We have
$o\in R(i)\subseteq\widehat R(i)$, and every row of $R$ whose output
\outrelbase $o$ is a row of $\widehat R$ whose output \outrelbase $o$.
\end{proof}

\begin{definition}[Canonical system]
\label{def:canonical-system}
A system (Definition~\ref{def:system}) is \emph{canonical} when its basis is
$\mathcal B_P$ and it performs no \commitment event; its histories are then
exactly those of Section~\ref{sec:histories}.
\end{definition}

\begin{lemma}[Compound \commitments are \commitments]
\label{lem:compound-commitment}
The composite of a nonempty sequence of \commitments, defined wherever the
sequence is, is a \commitment.
\end{lemma}

\begin{proof}
Each step leaves the current input unchanged and maps a state to a state, so the
composite does too, and it removes a nonempty set of rows because the first
step does.  Suppose step $m$ removes $(k,u)$, and let $R_m$ be the table that
step $m$ leaves.  By Equation~\ref{eq:commitment-unsubsumed} for that step, no
row of $R_m$ at $k$ \outrel $u$; the final table is contained in $R_m$, so no
remaining row at $k$ \outrel $u$ either.
\end{proof}

A compound \commitment event therefore has the same effect as one that applies
the composite \commitment alone.  In a functional spec the composite removes
every row at each input it touches, so it empties.

\begin{definition}[Run under a basis]
\label{def:run-under-basis}
Fix a \commitment basis $\mathcal B$.  A \emph{run under $\mathcal B$} is a
finite transition sequence from a canonical state $\sigma_P(i)$ of input
events, output events (Definition~\ref{def:system-output-event}), and
\commitment events (Definition~\ref{def:commitment-event}) that use only
\commitments from $\mathcal B$.
\end{definition}

\begin{definition}[Canonical run]
\label{def:canonical-run}
The \emph{canonical runs} are the runs under the canonical basis
$\mathcal B_P$ of Definition~\ref{def:canonical-commitment-basis} with no
\commitment events; they are the runs of
Sections~\ref{sec:functional-calm}--\ref{sec:complete-calm}.
\end{definition}

To make the claim of Lemma~\ref{lem:canonical-equivalent} precise, call two
runs \emph{observably equivalent} when they start at the same canonical state
and agree once \commitment events are dropped: wherever one has
$\mathsf{input}(j)$ the other does, and wherever one has $\mathsf{output}(o)$
the other does.  They accept the same inputs and emit the same outputs, in the
same order, which is all the environment observes.  Observably equivalent runs
may differ in the \commitments their events apply, and hence in their
remainder tables.

\begin{proof}[Proof of Lemma~\ref{lem:canonical-equivalent}]
By induction on the events.  Both runs start at the same canonical state, so
their remainder tables are initially equal.  Suppose that before some event the
original run's table $R$ and the canonical run's table $\widehat R$ satisfy
$R\subseteq\widehat R$; we show that the inclusion holds afterward.  An input
event $\mathsf{input}(j)$ that is legal at $R$ is also legal at $\widehat R$.
It causes the table to lose every row whose input does not \inrelbase $j$, keeping
$R[\mathrm{in}\InputGe j]$ in the original run and
$\widehat R[\mathrm{in}\InputGe j]$ in the canonical run.  Since
$R\subseteq\widehat R$, the first remains contained in the second.  An output
event $\mathsf{output}(o)$ with $o\in R(i)$ takes $R$ to
$R[\mathrm{out}\OutputGe o]$.  By output containment
(Lemma~\ref{lem:output-containment}), the canonical run can issue the same
event at $\widehat R$, which takes $\widehat R$ to
$\widehat R[\mathrm{out}\OutputGe o]\supseteq R[\mathrm{out}\OutputGe o]$;
the canonical basis supplies $x_o$ if the event needs it.  A \commitment event
keeps the current input and only removes rows, so the canonical run skips it
and the inclusion still holds.
\end{proof}

\begin{corollary}[Reconciliation under any basis]
\label{cor:reconciliation-any-basis}
Let runs under any \commitment bases end at $(i_r,R_r)$, and let $j$ be a
common \indesc of the $i_r$.  If some continuations, whose output and \commitment events
may apply any \commitments, bring them to a common state with current input $j$,
then some $u\in\fiber{j}$ \outrel every output emitted on every run.
\end{corollary}

\begin{proof}
The common state has a row $(j,u)$, and events never add rows, so
$(j,u)\in R_r$.  By Lemma~\ref{lem:canonical-equivalent}, $R_r$ is contained in
the table of a canonical run with the same inputs and outputs, and
Lemma~\ref{lem:run-residual} makes $u$ \outrel the outputs of run $r$.
\end{proof}

The converse of Lemma~\ref{lem:canonical-equivalent} fails: a canonical run
need not be observably equivalent to any run under a particular system's
basis.  That basis may lack the \commitment an
output event requires, and so disable the output altogether.  Such a system
still makes sound behavioral choices from $P$, but its strategy does not remove
the disabled canonical run from the spec.  Restricting attention to the runs
that one system produces could therefore hide non-monotonicity and hide the
canonical run that conflicts with a \commitment.  Consistency and the semantic
effect of \commitments are instead judged against the canonical runs permitted
by the declared spec.  A behavioral restriction narrows that comparison only
when it is part of the declared contract.

\paragraph{Application-specific \commitments.}
Locks and timestamps are \commitments of this kind: two-phase locking applies a \commitment that fixes an order among some transactions, and timestamp assignment places one transaction
relative to all others.  Section~\ref{sec:systems} illustrates both, and
Appendix~\ref{app:cc-bases} writes the two bases down.
